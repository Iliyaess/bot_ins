# Экскурсии КМВ: листовка и бот

## Листовка A6

Папка `flyer/`. Одна листовка на все точки раздачи с одним QR-кодом на бота в MAX.

- `config.json` — телефон, ссылка на бота, место сбора в Ессентуках, поездки недели и цены.
- `make-flyer.js` — собирает листовку из `config.json`.

Сборка:

```
cd flyer
npm install
npm run build
```

Результат в `flyer/out/`:

- `listovka.pdf` — файл для типографии: обрезной формат 105×148 мм, вылеты по 2 мм, шрифты встроены;
- `listovka-front.png`, `listovka-back.png` — превью.

Пока в `config.json` стоит `"sample": true`, на QR-коде печатается плашка «ОБРАЗЕЦ». Когда появятся настоящий телефон и ссылка на бота, поставьте `false` и соберите заново. QR ведёт на ссылку бота с меткой `start=listovka`, так бот отличает гостей с листовки от остальных.

Для сборки нужен Playwright с Chromium: он берётся из проекта или из глобальной установки.

## Карточка экскурсии в боте

`bot/kartochka-ekskursii.md` — шаблон карточки, пример для Эльбруса и заготовка поездки после процедур.

`bot/prometey-ekskursii.md` — экскурсии турфирмы «Прометей» (Ессентуки): время, цены, доплаты и что уточнить перед запуском.

`bot/taneks-ekskursii.md` — экскурсии бюро «Танэкс» (Кисловодск): что нашлось в открытых источниках и что уточнить.
